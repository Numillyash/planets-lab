## Документированное правило и область применения

Официальный [Starbase Mine Sweeping](https://help.planets.nu/adv-starbase-mine-sweeping) и [Minefields](https://help.planets.nu/minefields): Campaign Starbase Mine Sweeping — отдельное преимущество, **отключённое по умолчанию**. После включения `Sweep Mines` PRIMARY order база может очищать normal и web минные поля, причём все защитные лучи **планеты + базы** используют один тип — **высший beam tech, который starbase может строить**, независимо от обычного типа планетарной защиты. Базовое количество разрушенных мин для каждого типа луча переиспользовано из 10 документированных стандартных семей `STANDARD_BEAM_SWEEP_YIELDS` модуля #293. Starbases sweep AFTER ships; dedicated documentation говорит BEFORE scoop, однако полного самостоятельного order verification нет, и эта модель **не выполняет** scoop или многобазовую хронологию.

Новый `src/planets_lab/rules/starbase_mine_sweeping.py` реализует `quote_isolated_campaign_starbase_mine_sweep`, immutable `SweepingStarbase`, `StarbaseSweepFieldQuote`, `IsolatedStarbaseMineSweepQuote` и `StarbaseMineSweepAbstain`. Принимает **ровно одну** базу и полный **явно предоставленный** roster минных полей после изолированной корабельной очистки, но до этой конкретной базы. Автосоставления с #293, #294, #295 и с полным Host turn нет.

**Строгие предусловия:** все explicit provenance Boolean flags должны быть exact `True`: Campaign+включённое преимущество, точное количество лучей from planet and base, подтверждённый максимальный buildable beam family, полный post-ship/pre-base roster, неизменный enemy/ion context, отсутствие иных баз и взаимодействующих scoop/custom. `primary_order=="SWEEP_MINES"`, 1 <= combined defense beams <=2000 (локальный arithmetic guard, **не** NuHost limit), конкретные типизированные owner/base IDs/координаты, max radius100 или150, exact map enemy-by-field-ID, ion storm center for ALL fields и standard-web-yield для ALL web fields. Own field нельзя пометить enemy. Преимущество, owner, beam tech, primary order **предъявляются вызывающей стороной**, а не извлекаются из реальных Host receipts. Nonstandard web sweeping strength, dynamic weapons, dense/custom, многобазовый порядок и near-edge geometry → атомарный ABSTAIN.

Модель применяет документированные пороги `normal: dist < integer_radius + 5LY` и conservative PRE_DECAY web-circle #301 `INSIDE_CONFIRMED`/ `EDGE_ABSTAIN`/ `OUTSIDE_CONFIRMED`; ion-field center blocks sweeping; enemy false suppresses. Считает для каждого поля `min(field_units, (planetary_defense_beams+starbase_defense_beams) * yield_for_highest_buildable_beam)`; результаты отсортированы по field ID, не затрагивают исходный объект. Результат — `field_quotes`, `fields_hypothetically_after`, exact `initial = final + hypothetically_destroyed`. Поля Host flags **всегда false**: advantage activation, ship sweep execution, order acceptance, actual starbase sweep, phase order, inventory mutation, DIFF_VERIFIED.

`tests/test_starbase_mine_sweeping.py`: все 10 beam families × normal/web, общая мощность защиты, использование buildable tech планетой, normal strict 5LY, web pre-decay edge ABSTAIN, ion-storm и enemy, исчерпание нескольких полей и полное сохранение units, sorted determinism and immutability, явное включение Campaign/advantage, strict wrong order/loadout/sources/typed flags/no multi-base.

**Статус:** `DOCUMENTED + TESTED conditional` только после exact final PR CI. Ни одного реального Host/corpus/on-host experiment, нет runtime wrapper для synthetic-only. Не `CORPUS_OBSERVED`, не `DIFF_VERIFIED`.
