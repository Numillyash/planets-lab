# PR #299 — один условный web-hit: точный расход Neutronium

Дата: 2026-10-24. Источник: [официальные Minefields, Web Mines/Mine Impact](https://help.planets.nu/minefields) и [Fuel Consumption Details](https://help.planets.nu/fuel-details). Предыдущий main перед PR #299: `d84c591c1ec2c502743860f4fb245f058cbc3925`, #298 CI #1623 и main #1624 успешны.

## Подтверждённая механика и границы

При **одном уже состоявшемся** попадании web-мины звёздолёт тратит **весь Neutronium, рассчитанный для запланированного перелёта**, независимо от фактически пройденного пути, и дополнительно теряет `max(50 KT, 1/6 начального за ход Neutronium)`. При попадании останавливается и устанавливает Warp 0; действия при обнулении миссии, топлива, попадании в warp well и последовательности попаданий — отдельные механизмы. Клиентская оценка топлива может быть неверной; этот модуль НИКОГДА не вычисляет расход на перелёт самостоятельно и принимает только отдельно документированное целое значение. Внешний input должен учитывать source-true состояние после всех предшествующих действий Host; мы **намеренно исключаем** даже подтверждённый web drain, чтобы не смешивать фазы.

Официальный текст **не определяет округление дробного значения 1/6 KT** и не утверждает как нужно ограничивать отбор топлива при его нехватке. Поэтому чистый `quote_exact_single_web_mine_hit_fuel` делает условную котировку ТОЛЬКО если: (a) начало хода `F<=300` KT, тогда `max(50,F/6)==50` строго для любого дробного остатка, либо (b) `F>300` и `F % 6 == 0`, тогда дополнительный расход `F//6` точен. Если `F>300, F%6!=0`, **ABSTAIN**. Если `fuel_for_entire_scheduled_journey + extra > current_pre_movement_fuel`, **ABSTAIN** вместо домысливания ограничения нулём/специальных эффектов.

## Реализация

Новый `src/planets_lab/rules/web_mine_hit_fuel_quote.py`: immutable `WebMineHitFuelQuote`, `WebMineImpactFuelAbstain` и отдельная quote-функция. Strict typed целые значения `start_of_turn_neutronium_kt`, `pre_movement_neutronium_kt`, `scheduled_journey_fuel_kt` в диапазоне 0..1_000_000 (локальный арифметический guard, НЕ заявленный предел Host). Strict `ship_under_tow=False`; `start_of_turn==pre_movement` только при подтверждённом отсутствии prior fuel/phase changes. Требуются explicit exact True flags для standard settings, own-vs-enemy/source, independent accurate scheduled fuel, **one** web impact, отсутствия modifiers, drains, other effects. Такие caller flags не доказывают реальное Host execution.

Отдаёт breakdown: `shield_burn_neutronium_kt`, `externally_confirmed_scheduled_journey_fuel_kt`, `hypothetical_total_impact_related_fuel_used_kt`, `hypothetical_remaining_neutronium_kt` и `shield_burn_basis`, проверяя целочисленное conservation. `stopped_at_warp_zero_if_hit=True` — только documented условное следствие. `actual_web_mine_hit_verified=False`, `scheduled_movement_calculated=False`, `actual_fuel_inventory_mutated=False`, `waypoint_or_actual_position_calculated=False`, `out_of_fuel_mission_effect_calculated=False`, `web_drain_phase_executed=False`, `host_diff_verified=False` всегда. Нет реальных путей/позиции, случайности, области мины, геометрии, накопленного урона, команды Host, списаний или подключения к `HostEngine`.

`tests/test_web_mine_hit_fuel_quote.py` проверяет 50/299/300/306/600/900 KT, строгие не кратные 6 отказов, недостаток топлива и точный ноль, type bool masquerading, towing, missing evidence flags, immutability и отсутствие Host claims. **Только synthetic CI**, статус `DOCUMENTED + TESTED conditional` после exact финального CI; не CORPUS_OBSERVED/DIFF_VERIFIED. Никакого нового on-host/corpus/Host experiment или evidence runner.
